# ASEC

A Flutter app for a learning centre: the admin uploads lesson videos and writes
timed multiple-choice quizzes; members watch, take the quizzes while they are
open, and get marked straight away.

* One admin — `adminamr@gmail.com`. Everybody else registers as a member.
* Firebase Auth, Firestore and Cloud Storage.
* Arabic and English, RTL included.
* One codebase for phone, tablet, desktop, macOS and web.

See **SETUP.md** to run it.
